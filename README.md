# Gmail Account Creator Bot

Telegram bot to create unlimited Gmail accounts without device verification.

## Features
- ✅ Create multiple Gmail accounts
- ✅ Skip phone verification
- ✅ Skip recovery email
- ✅ Random birthdays & genders
- ✅ Persistent storage
- ✅ Export accounts

## Commands
- `/create <first> <last> [count]` - Create accounts
- `/list` - Show all accounts
- `/stats` - Statistics
- `/export` - Export as JSON
- `/clear` - Delete all
